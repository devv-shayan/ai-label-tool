Privacy

Your video stays on your computer.

Last updated October 23, 2026

AI Label Tool runs in your web browser. It does not send your video to a server. It does not store your video. The tool does not use accounts, cookies, or analytics.

What the tool does with your video

When you choose a video, your browser reads the file. The tool changes a copy in your browser. You download the new copy. The file does not leave your computer.

What the site collects

The site is a static page. It does not use cookies or analytics scripts. GitHub Pages serves the site. GitHub may collect basic technical logs, such as IP addresses, to run and protect the service. GitHub handles these logs under its own privacy statement.

Read the GitHub privacy statement.

If you contact us

You can report a problem or ask a question in the issue tracker. GitHub will process the information you send. Do not put private video files or personal information in a public issue.

Changes to this page

The maintainer may update this page when the tool changes. The date above shows the last update.
